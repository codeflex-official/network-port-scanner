# Network Port Scanner - CodeFlex Task 2

A fast and lightweight Network Port Scanner built in Python for cybersecurity analysis.

### 👨‍💻 Developed By
**Sachin Kumar** - CodeFlex Official Internship

### 🚀 Features
- Scans Top 1024 Ports (1-1024)
- Multi-Threaded for Fast Scanning
- Service Name Detection (ssh, http, ftp etc.)
- Domain & IP Both Supported
- Error Handling & User-Friendly Output

### 🛠️ Tech Stack
- Python 3
- Socket Programming
- Threading Module

# Clone the repo
